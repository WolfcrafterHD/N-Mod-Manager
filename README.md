# N Mod Manager
Version 1.0.0
A very very Simple Mod Manager.
You need to already have a Mod Launcher run atleast once so the mod File even exists in you Minecraft Directory.
It's made for Linux and will work on other Os also (although the open mod manager button will not work / lead to crashes).
Free to use for non profit puroses, not allowed for AI training. (I know Big Tech will do it anyways, but this is a mater of respect and humanity between me and you!)
